# リポジトリWiki

[English](wiki.md) | [日本語](wiki.ja.md)

Wikiタブには、リポジトリと一緒に管理するドキュメントを置けます。セットアップ、リリース手順など、
プロジェクトの近くに残しておきたい情報に利用できます。

## ページを作成する

リポジトリの書き込み権限があるメンバーは、Wikiタブの**新しいページ**からページを作成できます。
タイトルとMarkdownの本文を入力してください。ページURLを空欄にすると、タイトルからURLを作成します。

タイトルは256バイト、ページURLは160バイト、本文は1 MiBまで入力できます。

## ページを編集する

**編集**を選び、タイトル、ページURL、本文を変更して、変更内容を入力します。保存するたびに新しい
バージョンが作成されます。履歴には、各バージョンを保存したメンバーと日時が表示されます。
バージョンを選ぶと、その時点の内容を確認できます。

ページを開いた後に別のメンバーが更新した場合、保存と削除は拒否されます。ページを再読み込みし、
最新の内容を確認してから変更し直してください。

## Markdown

見出し、リスト、チェックリスト、表、リンク、画像、引用、コードブロックを表示できます。HTMLは
そのまま表示されません。

## 権限

リポジトリの読み取り権限があればWikiを閲覧できます。ページを作成、編集、削除できるのは、
リポジトリの書き込み権限、メンテナー権限、管理者権限があるメンバーと組織の所有者です。

ページを削除するとWikiタブには表示されなくなります。削除した記録は組織の監査ログに残ります。

## Webhook

リポジトリ管理者はWebhookの設定で**Wiki**を選択できます。ページを変更すると、`wiki.created`、
`wiki.updated`、`wiki.deleted`イベントが送信されます。
