# プルリクエストをレビューする

[English](pull-request-reviews.md) | [日本語](pull-request-reviews.ja.md)

プルリクエストを開き、**変更ファイル**を選択すると差分を確認できます。差分の左右どちらかの行番号を選び、
コメントを入力して会話を開始します。左側は変更前の対象ブランチ、右側は変更後の内容です。

行コメントを付けられるのは、差分全体を表示できるテキストファイルです。バイナリファイルと省略された差分は
確認できますが、行コメントは付けられません。

## ドラフトのプルリクエスト

レビュー前のプルリクエストを作る場合は、**ドラフトとして作成**を選択します。ドラフトにもコメントやレビューを
追加できますが、マージはできません。

レビューを依頼できる状態になったら、**会話**タブで**レビュー準備完了にする**を選択します。作成者とtriage権限が
あるユーザーは、レビュー準備完了への変更とドラフトへの戻しを行えます。対象ブランチを更新する直前にもドラフト
状態を確認します。

## 会話を続ける

リポジトリを閲覧できるユーザーは、レビューの会話に返信できます。会話を開始したユーザー、プルリクエストの
作成者、書き込み権限があるユーザーは、会話を解決済みにしたり再開したりできます。

コメントを編集または削除できるのは、コメントの作成者と書き込み権限があるユーザーです。削除したコメントは
返信の流れを保つため、削除済みの表示で会話に残ります。

## レビューを依頼する

プルリクエストの作成者とtriage権限があるユーザーは、リポジトリを利用できるユーザーまたはチームへレビューを
依頼できます。**会話**タブの**レビュアー**でユーザーまたはチームを選び、**依頼**を選択してください。

各レビュアーには、現在のソースリビジョンへ送信されたレビュー結果が表示されます。複数の有効なチームメンバーが
回答した場合は、変更要求、承認、コメントの順で結果を表示します。レビューが不要になった場合は依頼を削除
できます。

## 新しいリビジョンをレビューする

ソースブランチまたは対象ブランチが変わると、それまでの差分に付けた会話は**古い差分の会話**へ移ります。
移動後も返信できます。変更後の行について話す場合は、現在の差分から新しい会話を開始してください。

承認と変更要求は現在のソースリビジョンに適用されます。**会話**タブから送信してください。ソースリビジョンが
変わると、依頼したレビュアーは新しいリビジョンをレビューするまで**レビュー待ち**に戻ります。

## プルリクエストを整理する

triage権限があるユーザーは、**会話**タブでラベル、担当者、マイルストーンを設定できます。担当者はリポジトリを
利用できるユーザーから10人まで選べます。ラベル、担当者、マイルストーンを外しても、プルリクエストの状態と
レビュー履歴は変わりません。
